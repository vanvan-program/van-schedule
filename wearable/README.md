# van手环 0.3.0（应用与同步版）

面向小米手环10 Pro个人侧载。手环应用显示今天／明天的课程、时间、地点和详情，隐藏已结束课程，区分无课、假期、整日停课、未同步及缓存超期；手机负责计算同步日起14天的实际课程，手环保留离线缓存。

2026-10-25按用户要求移除手环系统小组件。当前RPK versionCode **9**不含独立卡片入口、原生模块、实验表盘和原生小组件缓存桥；仅使用应用原有双槽JSON缓存。Android versionCode **30**移除手环卡片说明，其余手机功能与桌面小组件保留。

## 安装

使用同套 van课表-0.3.0.apk 与 van手环-0.3.0.rpk，保持原包名app.van.timetable、原签名与数据格式，直接覆盖已有应用，不卸载、不清数据。

若此前启用过原生日历位实验，正常重启手环一次即可清掉临时内存替换，再切换到普通表盘；旧课程实验／诊断表盘可删除，不再启用。无需恢复出厂，也不需要现在重新联调。

同步时断开电脑AstroBox，确认手机小米运动健康连接手环；在手环打开van手环，手机“我的 → 手环课表”选择立即同步或示例验证。设备连接与授权不等于课程同步；手机收到手环完整保存后的ACK才显示成功。自动同步受手机后台限制，前台手动同步仍可使用。

手环返回按钮：详情返回列表、明天返回今天、今天退出；今天右滑及系统返回同样可退出。

## 构建与验证

Node.js18+、Java21；在本目录执行npm install，再运行 ./build-band.ps1 -JavaPath <Java21目录>。本机亦可复用工程 .tools/vanband/toolchain 的固定aiot-toolkit2.0.5。构建脚本核对成功标记及新RPK生成时间。Windows工具链需要目录联接／符号链接权限。

运行 npm test。当前保留16项协议、原有双槽缓存、Unicode分片、损坏／写入中断、今日／明日与跨天、课程结束、页面布局和返回导航、ACK与失败提示测试，均通过。

签名使用根目录本机signing.properties和KeystoreSign.java，原私钥留在keystore内，仅输出公开证书与签名。源码ZIP不包含私钥、凭据、个人课表或设备AuthKey。生成 dist/app.van.timetable.debug.0.3.0.rpk，仅用于个人侧载。

## 同步协议

手机经运动健康SDK、手环经@system.interconnect通信，协议仍为version1。chunk含requestId、index、count、UTF-16 FNV-1a校验值和字符串片段。手环完整接收并校验后写入非活动JSON槽，回读后切换提交指针，最后发送ack；失败保留旧缓存。request请求手机刷新，clear仅清手环课表，不改手机课程。

此次保留所有已经修复的通信行为：回调先于缓存加载建立、接收等待缓存初始化、读写超时、直接发送Object以避免202 invalid args，以及手机端避免重复注册监听。

问题、历史实测边界与移除范围见 [阶段总结](../docs/0.3.0-手环阶段总结与小组件移除.md)。实验材料仅保存在本机archive/2026-10-25-手环小组件停用/，不在当前构建和源码交付中。
