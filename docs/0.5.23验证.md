# van课表 0.5.23 验证

2026-11-28。Android 版本代码 73，架构 `arm64-v8a`。

- 使用 GitHub 正式版 v0.5.22 的 ARM64 APK 作升级起点。Android 16 模拟器上覆盖安装 v0.5.23 后，7 份已有测试课表的 ID 和内容逐条一致，设置文件 SHA-256 一致。两版证书一致，新包通过 APK v2 签名校验。
- 在签名 Release 包上核对了三个桌面小组件提供者、日周视图往返、多课表切换和恢复，以及通过 JNI 调用的中英文离线 OCR。
- 领域层 166 项和应用层 39 项 JVM 测试通过。版本号更新前，同一套功能改动还通过 11 项 Android 16 设备回归，覆盖同周和跨周拖课、桌面组件独立绑表、补课撤销及熄屏提醒。
- 性能对照在 Android 16 软件渲染模拟器上完成。相对上一轮本地优化构建，35 门课中含 1 门自定义时间课程时，判断能否折叠课间的中位耗时从 77.95 ms 降至 3.02 ms。连续 12 次普通时钟更新触发的「下一节」搜索从 12 次降至 0 次，跨过上课和下课时仍各更新 1 次。
- 连续翻周各轮 P95 帧耗时由 150 ms 变为 133–150 ms。实体手机性能和熄屏行为尚待验证。
