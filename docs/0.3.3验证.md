# 0.3.3 版本信息与检查更新验证

本次在 0.3.2 源码基础上新增“关于版本”与联网检查更新。包名 `app.van.timetable`，versionCode 33，versionName 0.3.3，沿用 0.3.2 的包结构、签名与裁剪配置。

## 需求

设置（“我的”）内提供版本信息与“检查更新”；点击后联网判断是否为最新版本，不是最新时提示并给出最新版本。

## 修改

- 新增“我的 → 关于版本”页面：显示 versionName、versionCode、包名、Android 版本与许可，提供“检查更新”“历史版本更新”“开源与第三方许可”。
- “帮助与关于”新增“版本与更新”入口；隐私说明补充“检查更新只读取公开版本信息”。
- `core:domain` 新增 `UpdateCheck`：版本号规范化（去 v 前缀，忽略预发布／构建后缀）、逐段数字比较、GitHub 发布动态（`releases.atom`）解析（标题、发布时间、发布页地址、更新说明 HTML 转纯文本）、`/releases/latest` 跳转地址解析。
- `app` 新增 `UpdateChecker`：优先读取发布动态（不受 GitHub API 按小时限流），失败后用 `/releases/latest` 跳转兜底取版本号；8 秒连接、12 秒读取超时；403/429、404、5xx、超时、DNS、连接、TLS 分别给出中文提示。
- 关于版本页：发现新版本时显示版本号、发布时间（UTC 转本机日期）、更新说明（默认 8 行，内容被截断时可展开），提供“打开下载页”“复制下载链接”，并弹出一次更新提示；检查失败时显示原因，提供“重试”和“打开发布页”。
- 检查只在点击时发起，只读取公开的版本号与更新说明，不上传课表、账号或设备标识；本机不保存检查记录，也不在后台自动联网。
- 版本号 0.3.3／33，`assets/changelog.txt` 新增 0.3.3 条目并默认展开，README 增加对应说明。

真实发布页解析使用本机下载的发布动态做一次临时验证（测试文件在验证后删除，未进入仓库），确认线上格式能被解析：版本 `0.3.2`、标题“van课表 0.3.2 · 小组件添加反馈”、说明转成标题与 `• ` 列表、页面地址指向 `releases/tag/v0.3.2`。

联网检查另用临时测试直接调用 `UpdateChecker.check`（与手机相同的请求、解析与比较代码）跑通三个分支：本机 0.3.2 返回已是最新；本机 0.1.0 返回发现 0.3.2，附带 641 字符更新说明与发布页地址；本机 9.9.9 返回已是最新。该测试同样在验证后删除。

**网络环境**：本机直连 GitHub（`curl` 不带代理）20 秒超时，经本机 HTTP 代理可正常访问（约 0.9 秒返回 200）。因此联网检查在能访问 GitHub 的网络下可用；手机若没有代理／VPN，会按代码显示超时提示并可打开浏览器发布页。

更新源固定为 `github.com/vanvan-program/van-schedule` 的 Release（与 README 下载链接一致）：发布时必须使用 `v版本号` 形式的 tag，检查逻辑取第一条发布的标签作为最新版本。仓库改名或迁移时，需要同步修改 `UpdateChecker.REPO`。

新增的 10 项 `UpdateCheckTest` 覆盖：版本号规范化（v 前缀、预发布／构建后缀、非法文本）、按数字而非文本比较（`0.2.10` 大于 `0.2.9`）、缺版本号时不猜测、发布动态取最新条目并转纯文本、空发布动态、发布动态只认 `<link>` 标签（更新说明里引用旧版本发布页时不误判）、发布页跳转地址（含查询串、非 tag 地址）、HTML 转纯文本（标题、列表、脚本、实体）、命名与数字字符实体。

## 未验证

- 当前没有连接安卓设备，未在实体手机或模拟器上打开“关于版本”、点击“检查更新”、查看更新弹窗、跳转浏览器或复制链接。界面渲染与交互仍需设备核对；联网分支已在 JVM 上用同一套代码验证。
- 未在无代理／弱网／移动数据下验证失败提示的实际显示；失败分支由代码与超时实测（直连 20 秒超时）覆盖。
- 发布动态不区分预发布（Pre-release）：若以后发布高于当前版本的预发布，检查也会提示。目前只发布正式版本；需要区分时应改用 GitHub API 的 `prerelease` 字段（该接口有按小时限流）。
- 0.3.3 尚未发布，安装本包点击“检查更新”会显示“本机版本较新（发布页最新 0.3.2）”。要核对“发现新版本”分支，可先安装 0.3.1 及更早版本后再检查。
- 检查更新不下载、不安装 APK；安装仍需在浏览器下载后覆盖安装，未申请安装未知来源权限。
- 发布到 GitHub 的 Release 与 SHA-256 校验文件需在发布时另行生成。
