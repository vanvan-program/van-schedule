# 0.3.2 界面修正版验证

2026-10-31。versionName 0.3.2，**versionCode 33**，可覆盖原 0.3.2（versionCode 32）。

## 修改

- 周次条只绘制 4 dp 细线和 12 dp 圆点。浅色模式使用深蓝圆点；深色模式使用适配背景的蓝色。去掉两端 1／20、右侧第几周文字和整条刻度点。
- 保留 48 dp 触控高度、拖动切周、原有动画和无障碍周数说明；上方原有第几周入口保留。
- 进度条移到周次说明栏下方，更靠近底部导航。
- 左侧节次和起止时间以实际字体、字号测量最小宽度与行高；三行标签保持单行文字。当屏幕或字号不允许整周放下时使用纵向滚动，保证起止时间完整，避免把最后一行压小或遮在进度条后面。

问题不仅是进度条的位置。原实现采用固定的最小行高估计，手动行高也未保证字体所需高度。11 节课、1.3 倍字号与紧凑行高的复现中，结束时间曾只分到 **4 px** 高度；修正后该行获得完整的 **15 px** 字体布局高度。没有靠缩小字号处理。

## 验证

- **91 项 JVM 测试通过**。
- **31 项模拟器测试通过**：2 项本次专项、11 项 0.3.2、4 项 0.2.8、6 项分页、6 项 0.2.6 和 2 项导航回归。
- 对 11 节课，在 1.0／1.15／1.3 倍字号及手动紧凑行高中逐项检查，共 **132 个标签布局**，校验实际文字宽度、段落高度和进度条上方边界；浅色、深色截图已核对。
- 独立 Release 测试器验证原 0.3.2 build 32 → 修正版 build 33 覆盖升级：课表 payload、设置摘要和小组件组件名一致；裁剪包离线中英文 OCR 运行正常，**2 项检查通过**，另有 1 项升级基线采集通过。
- Debug／Release 构建成功。Lint 均为 **0 错误**，Debug 79 条、Release 79 条警告。最终崩溃缓冲区为空。
- 模拟器为 Android 15 / API 35、360×800 dp。未在实体手机重新安装或验收。

文字校验使用实际行宽和段落高度。Compose 的紧凑文字布局可能把剩余段落宽度也计入通用溢出标志，测试未将这个标志直接当成字形裁切。
