# 0.3.4 课程合并与周次进度条验证

本次把并行开发的手环版之外一条分支——朋友交接的“0.3.2 进度条开关版”（versionCode 34）——并入 0.3.3 主线。包名 `app.van.timetable`，versionCode **35**，versionName **0.3.4**，沿用 0.3.3 的包结构、签名与裁剪配置。分支 `release/0.3.4`，合并提交 `addecf5`。

## 合并来源与基线

交接源码包 `van课表-0.3.2-build34-开发交接源码.zip` 的分叉点是本仓库的 0.3.1（`f8821b8`）：它不包含 0.3.2 的小组件添加反馈，也不包含 0.3.3 的版本信息与检查更新。因此不能整包覆盖，按 0.3.1→交接版的三方合并处理。

| 处理 | 文件 |
| --- | --- |
| 直接采纳 | `core/domain` 的 `CourseGroups.kt`、`Models.kt`（新增 `showWeekProgress`）；`ui` 的 `RoutineScreen.kt`、`SelectionColors.kt`、`WeekScrubber.kt`、`WeekSelectionField.kt`、`MainScreens.kt`、`EditorScreens.kt`、`SectionRangeField.kt`、`WeekGrid.kt`、`SettingsScreens.kt` |
| 手工解决冲突 | `assets/changelog.txt`（两边都在顶部新增条目）、`ui/ChangelogScreen.kt`（默认展开条件） |
| 自动合并后人工核对 | `ui/SettingsScreens.kt`（进度条开关与 0.3.3 的“版本与更新”入口） |
| 采纳测试 | `CourseGroupsTest`、`WeekProgressPreferencesTest`、`Version032UiTest`、`TimetableChromeTest` 及更新后的 `Version023/024/026UiTest` |
| 保留主线 | 0.3.2 小组件添加反馈（`WidgetPinRequest.kt`、`VanApp.kt` 小组件区）、0.3.3 版本信息与检查更新（`UpdateChecker.kt`、`VersionScreen.kt`、`UpdateCheck.kt`） |
| 不采纳 | 交接包把厂商 `xms-wearable-lib_1.4_release.aar` 一并纳入版本库的 `.gitignore`／第三方声明改动；公开仓库仍不附原始 AAR，按 `app/libs/README.md` 自行获取 |

## 合并后的行为

- “课程”页按 `parentCourseId` 合并正课、实验课与期末考试；详情按区块查看，可单独编辑、开提醒、删除关联课程，删除正课时明确提示关联课程保留。课程合并只改展示，不迁移数据库记录。
- 课表底部周次滑动条：拖动预览、松手动画切换，与日列表、左右翻页、回到本周联动；“我的 → 外观设置 → 显示周次进度条”可关闭并释放占位，设置随完整备份保存。
- 课程编辑：周次改为可滑动多选的弹窗网格；星期／开始节／结束节合并为滚轮；指定单次日期后隐藏星期与周次。
- 作息管理：逐节起止时间列表，滚轮编辑并增减每天节数，保存前检查时间先后、相邻重叠与课程占用。
- 周网格左侧节次与时间按实际字体测量最小行高／宽度，紧凑布局与大字号下不再裁切结束时间。
- 历史更新条目统一编号与新增／优化／修复／调整分类，默认展开最新版本。
