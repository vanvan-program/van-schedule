# 0.4.0 柔光玻璃质感、跨周拖拽与莫奈取色验证

包名 `app.van.timetable`，versionCode **40**，versionName **0.4.0**，沿用 0.3.4 的包结构、签名与裁剪配置。发布提交 `3cd78b9`（tag `v0.4.0`），相对 0.3.4 的收尾提交 `a92dde1` 改动 30 个文件、+8548/−371 行。本版在 0.3.4 功能之上合入 `:softglass` 材质、Nexio 交互移植与莫奈取色。

## 本次改动

- **材质与外观**：本地集成 `:softglass` 材质模块（Apache-2.0，`com.haooz.softglass`），“我的 → 外观设置”提供柔光玻璃／清透磨砂／无材质切换，可调卡片着色、不透明度、模糊、折射与 Squircle 连续圆角，并支持背景壁纸亮度／模糊调节与开关即时预览。
- **莫奈取色**：Android 12+ 跟随系统动态配色，应用内配色、课程配色协调与桌面小组件实例独立莫奈开关均支持；壁纸变化时刷新。
- **跨周拖拽调课**：周课表长按 320ms 进入拖拽，跟手高光浮层、边缘停留自动翻页，落在其它周次时给出冲突覆盖／互换确认；原有课程详情、按周备注与长按／点击交互保留。
- **课表与作息管理**：作息可设为默认作息、自定义节次名称与当前上课节次高亮；全局调休跟随绝对日期跨课表生效；课表支持排序上下移动与“开启新学期”。
- **动效与过渡**：顶栏使用 AGSL 渐进模糊（低版本回退轻量模糊），底栏与菜单支持滑选触发与动态指示器，接入预测性返回手势动画与文字变化模糊过渡。
- **排序与合规**：日列表可按上午／下午／晚上分组（外观设置可关），课程列表改用中文拼音与数字自然排序；补充 AGPL-3.0 与 Apache-2.0 第三方组件声明（`assets/licenses/AGPL-3.0.txt`、`THIRD_PARTY_NOTICES.md`、应用内许可页）。

新增源码集中在 `ui/nexio/`（`NexioDragSelect.kt`、`NexioGlassSupport.kt`、`NexioProgressiveBlur.kt`、`NexioTextMotion.kt`）、`widget/WidgetMonetHelper.kt` 与 `:softglass` 模块；`WeekGrid.kt`、`MainScreens.kt`、`Theme.kt`、`SettingsScreens.kt`、`VanApp.kt`、`CourseEngine.kt` 为主要改动文件。
