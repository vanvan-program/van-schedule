# 0.3.2 课程合并与时间编辑验证

2026-10-31。包名 `app.van.timetable`，versionName **0.3.2**，versionCode **32**。
按用户提供的 `0.3.2.md` 开发，保留现有浅深色配色、离线 OCR、课表数据格式与原签名。

## 需求对应

| 需求 | 实现 |
| --- | --- |
| 课程合并 | “课程”页按已有 `parentCourseId` 关系将正课、实验课、期末考试合为一项。详情按类型分区，关联课程可独立编辑、删除和设置提醒；搜索、备注搜索和本周筛选包含所有关联课程。 |
| 底部滑动条 | 底部离散周次滑动条显示周数。拖动时只预览，松手后沿用课表分页动画切换；左右翻页、周次菜单、回到本周和日列表保持同步。单周学期禁用滑动。 |
| 周次选择 | 改为五列网格弹窗，支持点击和滑动连续选择／取消。使用蓝色选中态，不增加单双周或全选入口。空选择不能保存；取消不改变原值，重建后保留草稿。 |
| 星期和节次 | 合并为上课时间入口，弹窗内用星期、开始节和结束节滚轮。结束节不早于开始节。指定单次日期后隐藏星期及周次；清除日期后恢复重复设置。无固定时间仍支持整周实践。 |
| 作息管理 | 显示逐节起止时间列表，点击用小时／分钟滚轮编辑。可增减每天节数，检查时间先后、相邻时段重叠和课程占用。保留多套作息及生效日期规则，另存后选中新作息。 |
| 更新目录 | 所有历史版本条目增加从 1 开始的编号和新增／优化／修复／调整分类。默认展开最新版本。 |

课程合并仅调整展示，不迁移或合并数据库记录。没有关联的同名课程仍独立显示，关联丢失或异常的数据不会被隐藏。删除正课时明确提示关联课程将保留为独立课程。

本次同时验证学期开始前／结束后的课程筛选；单节作息中新课程及新增时段默认使用第 1 节，避免默认占两节导致无法保存。作息编辑不自动截断已有课程。
