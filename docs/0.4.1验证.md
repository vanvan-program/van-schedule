# 0.4.1 UI 结构重排与翻周性能验证

包名 `app.van.timetable`，versionCode **41**，versionName **0.4.1**，沿用 0.4.0 的包结构、签名与裁剪配置。发布提交 `118c4e2`（tag `v0.4.1`），相对 0.4.0 的收尾提交 `0f677a7` 改动 24 个文件、+2892/−1909 行。本版不新增功能、不改数据库与备份格式，只重排 UI 层并修正一处翻页开销。

## 本次改动

- **类型化导航**：新增 `ui/navigation/VanRoute.kt`，把字符串 route 改为密封目的地（32 个目标），参数在 `vanRouteOf` 一次解析并校验；`VanRoute.key` 与 0.4.0 的字符串 route 完全一致，因此返回栈、`SaveableStateHolder` 的键与旧存档继续命中。`nav("...")` 签名未变，50 余处调用点零改动。
- **分发集中**：屏幕分发从 `VanApp` 的 `when` 分支移入 `ui/navigation/VanNavHost.kt`，`when` 对密封类型穷尽检查，新增页面漏接会编译失败；标题与目的地同源定义，不再有第二份 `title()` 清单。
- **外壳瘦身**：`ui/VanApp.kt` 由 725 行降到 479 行，只保留主题、壁纸、顶栏底栏、返回栈与文件结果回调；`ui/MainScreens.kt` 由 1020 行降到 127 行。备份、分享、桌面小组件说明拆为 `BackupScreen.kt`、`ShareScreen.kt`、`WidgetGalleryScreen.kt`，屏幕不再直接读写文件。
- **课表页拆分**：原 670 行的 `Timetable` composable 拆到 `ui/timetable/`：`TimetableScreen`（锚点、分页、拖拽状态机）、`TimetableHeader`（顶栏与两个下拉面板）、`TimetableChrome`（下一节提示、周备注、回到本周、拖拽提示与卡片副本）、`TimetableDialogs`（周次直跳与冲突处理）、`WeekGrid`、`TimetablePager`、`DayListScreen`、`GlassDropdown`。
- **翻页开销**：`WeekGrid` 的课程卡原先无条件挂 `graphicsLayer`，一屏 20 余张卡即产生同等数量的离屏合成层；改为只在被拖拽的卡片上挂层。与 0.4.0 逐行比对后，`WeekGrid` 与 `TimetablePager` 除包名、import 与该处图层外无差异，网格几何、卡片排版与拖拽逻辑未改动。
- **回归测试**：新增 `app/src/test/.../VanRouteTest.kt`，覆盖 32 个目的地的 key 往返、类型往返、旧字符串映射、畸形输入兜底与编辑器一次性 id 规则。

行为保持：返回栈语义、编辑器草稿隔离与退出清状态、深链与小组件跳转、导入成功后的落点、顶栏标题、全部 `testTag` 均与 0.4.0 一致。结构说明见 [UI 结构改造说明](UI结构改造说明.md)。
