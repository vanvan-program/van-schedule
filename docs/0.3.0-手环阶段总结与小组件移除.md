# 0.3.0 手环阶段总结与小组件移除

日期：2026-10-25。设备：小米手环10 Pro陶瓷版，固件3.101.043。用户决定停止小组件试验，当前仅保留手环应用与手机同步；不再请求用户安装诊断表盘或继续真机排查。

## 已经确认的可用部分

- 用户确认van手环可以安装、打开，后续已能正常显示课程。
- 用户确认手机显示“手环已确认保存14天课程”，手环显示“课程已保存，确认已回传”。正式课表发送、完整保存与ACK回传已有双端反馈。
- 手机的运动健康设备发现、设备管理授权和伴侣应用发现已核对通过。
- 手环应用代码提供今天／明天、课程详情、结束课程隐藏、无课／假期／停课状态、14天双槽缓存与缓存超期提示；代码和电脑检查保留。全部课程逐项核对、真实离线跨天和长时间后台同步没有完整真机验收记录，不能把这些都写成已验收。

## 遇到的问题与处理结果

| 问题 | 已定位原因／处理 | 当前结论 |
| --- | --- | --- |
| 打开应用后无法返回 | 首轮依赖手势不足；补充可见返回按钮、今天退出／明天返回今天／详情返回列表及系统返回处理 | 保留修复与导航回归；没有逐项真机验收记录 |
| 手机提示尚未连接，运动健康实际已连接 | 设备连接、授权、伴侣应用发现和课程保存混为一个状态；现分阶段检查，页面自动检查并可重试 | 用户确认设备、授权、应用发现均通过 |
| you have registered、保存确认超时 | 手机SDK拒绝重复注册消息监听；按重试生命周期注销旧监听再注册，并明确超时阶段 | 保留修复；后续正式课程保存ACK成功 |
| 手环发送失败202 invalid args | connect.send要求data为Object，旧版本传了JSON文本 | 改为Object，后续用户确认保存和ACK成功 |
| 保存成功但课程区域完全空白 | 原生list及list-item缺少明确高度，复用行子结构也需一致 | 设置高度并固定行结构，用户随后确认正常显示 |
| AstroBox突然AuthKey错误 | 工具显示认证密钥错误，后续用户确认连接恢复 | 独立于课表协议；未记录凭据 |
| 独立JS系统卡片不出现在列表 | 构建工具支持CARD和manifest声明，不代表零售固件宿主会注册该入口；补类型及尺寸后仍无效 | 实际适配失败，现移除 |
| 原生日历位接口不匹配 | 硬件状态、应用注册的两条表与最初假设不同，历次诊断逐步暴露差异 | 不能用固定指针猜测代替完整枚举证据 |
| 已移除日历卡片却显示仍被使用 | 旧提示把尺寸、地址、遍历上限及真实引用等多种拒绝统称“仍被使用” | 提示不准确；后续拆分D5-H/P/L/R/V |
| D5-P在3D4AA870停止 | 最初PSRAM范围太窄，在首节点前就拒绝 | 精确固件堆边界校验后修复6可继续；不是可见卡片仍占用的证据 |
| 修复6显示替换成功但没有课程卡 | 实际只替换B表中的1B／4821记录；添加列表读取A表 | 真机系统小组件验收失败；“替换成功”不代表列表可见 |
| 同ID安装表盘未实际更新 | 用户多次通过先删除旧表盘才看到更新 | 后续版本使用独立表盘ID，防止旧版本干扰判断 |
| 新组件ID／B表强行暴露的重启问题 | 原固件在部分保存组件查询路径缺少空指针保护；新ID或原UID只在B表时可查不到描述符 | 已拒绝这类方案，不应通过强行解绑或启动脚本绕过 |

## 停止时的最后状态

修复7转向另一套日历实现com.xiaomi.miwear.perpetual_calendar（应用45、原组件4891），要求A表启用、原UID可查、添加列表实际查询一致，写入后再检查，不恢复／迁移应用，不改查询分发表。88项ARM/Lua电脑检查包含完整添加列表过滤和名称回调，电脑夹具能生成课程分类记录。

**修复7没有收到真机安装或运行反馈，不能认定成功或失败。** 最后一个有真机反馈的原生版本仍是修复6：B表指针替换成功，但系统小组件列表没有课程速览。原生课程卡从未完成实际添加、绘制、同步刷新、离线跨天与重启恢复的整体验收。

我此前把指针替换结果呈现得过于接近功能成功，且对日历入口、地址范围、查询表的假设验证不足，增加了用户反复安装的成本。以后若恢复，应先在同固件核对真实启用记录、列表枚举及重启后的原UID解析，再安排明确目的的真机试验，不能继续靠改声明或模糊成功提示推进。

## 本次移除内容

- 从当前wearable源码移除src/cards、manifest.router.widgets、原生课程卡模块／Lua加载器和相关构建／打包脚本。
- 移除native-cache／native-export及专用ASCII缓存发布、相关状态文字与卡片专属测试；应用原来的JSON双槽缓存、提交键和同步协议不变。
- 移除手机“手环课表”页的系统快捷卡片说明，修正更新记录和安装文档。
- 清开旧手环build／dist再构建，实际RPK包中不存在cards资源或原生缓存依赖。
- 安卓仍为0.3.0，versionCode30；RPK仍为0.3.0，versionCode9，支持在现有29／8基础上递增覆盖。原包名、签名、数据库、课表、备注和设置保持兼容；手机原有桌面小组件保留。

实验源码、旧表盘、RPK与诊断说明保存在本机archive/2026-10-25-手环小组件停用/，退出当前构建、测试与新源码交付；本机固件／工具研究目录和.verification历史记录仅用于未来复盘。归档不代表继续开发授权。未改写个人课程或设备凭据，也未在本轮操作手环。

## 现有手环如何收尾

此前已加载的原生替换仅在内存中，正常重启手环一次可撤销；切回普通表盘，旧课程实验／诊断表盘可删除，不再点启用。新的纯应用RPK和手机APK可在方便时覆盖安装，无需现在操作，无需解绑或恢复出厂。旧专用缓存文件即使仍在应用私有目录也不会被新版读取、更新或发布，保留它们不会影响原JSON课表缓存。
