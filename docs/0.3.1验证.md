# 0.3.1 安装包与交互验证

本次保留原有功能、配色和布局，保留本机离线中英文 OCR。包名为 `app.van.timetable`，versionCode 31，versionName 0.3.1。

## 打包变化

| 内容 | 0.3.0 | 0.3.1 arm64 |
| --- | ---: | ---: |
| 签名 APK | 54,313,855 字节 | 13,432,195 字节 |
| DEX 压缩内容 | 20.58 MB | 约 1.72 MB |
| CPU 架构 | ARM32、ARM64、x86、x86_64 | ARM64 |

下载包缩小约 75.27%。开启 R8 优化、代码与资源裁剪、DEX 压缩；完整图标依赖中的未使用代码由 R8 删除。

Tesseract、Leptonica、图像编解码等 arm64 原生库及 `chi_sim.traineddata`、`eng.traineddata` 与旧 APK 的解压内容逐文件 SHA-256 相同。字库压缩后大小略有变化不代表模型被精简。OCR 的 Java/JNI 桥接提供显式保留规则；小组件持久化的组件名和手环 SDK 异常类名也保留。

签名证书 SHA-256 与原版一致：`2787e9a025cbd6606ac2ec05415432513ada6732360ce4dc2abb22e049e938bf`。数据库版本、序列化数据格式不变。

## 交互变化

- 底栏蓝色选中指示器连续滑动，图标文字颜色短时过渡；再次点击当前页不重复切换。
- 页面进入和返回采用短距离位移与淡入淡出。转场内容使用独立的目的地快照，避免退出页面读取新路由而显示错误内容。
- 周课表卡片按压缩至 97% 并回弹，松手或滑动取消后复位；动画值在绘制阶段读取，静止卡片不保留缩放图层。
- 课程详情标题卡轻量展开。采用系统 Compose 动画时长缩放机制。
- 原有分页跟手、吸附阈值、左右各一页预加载、日列表、字号放大时的横向滚动边界保留。

曾评估共享边界与扩大空闲预加载。密集课表测试中，共享布局增加翻页开销，扩大预加载没有稳定收益，两者均未纳入最终交付。Nexio 的代码没有直接复制，借鉴的是过渡连续性、按需图层与先测量再取舍的实现原则。

## 验证方式与证据

最终结果：87 项 JVM 测试、23 项模拟器界面回归、2 项独立 Release 检查全部通过；旧版升级基线采集通过。应用 Debug／Release 和独立测试器 Lint 均为零错误。最终汇总为 `.verification/031/final-checks.json`。

- 清理构建目录后构建 Debug、Release、AndroidTest；执行 82 项领域测试和 5 项应用 JVM 测试。
- 检查 Debug、Release Lint；已有硬编码文字、旧 API 等警告保留，错误数必须为零。
- 专用 Android 15 / API 35 x86_64 模拟器执行 23 项关键回归：周／日翻页、学期边界、返回与重建、备注编辑、图片／PDF 离线 OCR、识别核对、桌面小组件绑定、手环页面以及动画中途快速切换。
- 独立 `qa:release` 测试器直接对裁剪 Release 检查升级后课表 payload 和设置文件摘要、小组件组件名，以及通过已安装包的 Java/JNI 桥接识别合成中英文图片。完整的文件导入与核对编辑流程由前述 Debug 界面回归覆盖。
- 模拟器发布包仅原生架构与手机交付不同，比较 DEX 哈希确认裁剪代码相同。
- 本机证据位于 `.verification/031/`：`apk-audit.json`、签名、构建／测试日志、浅深色截图及性能实验记录。

密集课表三轮实验使用同一模拟器、35 张课程卡和相同往返手势。模拟器为软件图形渲染，JIT 与宿主负载引起明显波动；不据此宣称真机帧率提升。

本次未在用户实体手机安装或测量高刷新率表现，也未重新验收运动健康到手环的实际通信。手环页面回归不等于物理链路验收。

## 构建与安装

手机交付：`deliverables/van课表-0.3.1-arm64.apk`。使用原签名覆盖安装，勿卸载旧版或清除数据。

`./gradlew :app:assembleRelease` 默认构建 arm64 包。其他架构可通过 `-PvanReleaseAbis=armeabi-v7a,arm64-v8a,x86,x86_64` 选择；Debug 保留各架构。

独立发布测试器的操作见 [说明](../qa/release/README.md)，它不进入手机交付包。
