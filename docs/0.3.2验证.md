# 0.3.2 小组件添加反馈验证

本次修复“我的 → 桌面小组件”中点击“添加到桌面”没有任何提示、桌面也没有响应的问题。包名为 `app.van.timetable`，versionCode 32，versionName 0.3.2，沿用 0.3.1 的包结构与裁剪配置。

## 问题原因

原实现只判断桌面是否声明支持固定小组件，随后直接发起请求并忽略返回值。

桌面声明支持但实际拒绝请求，或请求发出后不弹出确认窗口时，应用不会显示任何结果；只有桌面明确返回“不支持”时才会提示，因此表现为点击无反应。

## 修改

- 三个组件的添加按钮分别处理桌面不支持、请求被拒绝、请求已发送与调用异常四种结果，并在按钮下方直接显示说明。
- “请求已发送”只表示请求已交给桌面，不宣称组件添加成功，避免误导。
- 页面新增“手动添加”说明和“返回桌面手动添加”按钮；找不到 van课表 时提示检查桌面的组件管理或添加权限。
- 提示显示在当前组件卡片内，不使用应用内弹窗，避免遮挡桌面可能出现的确认窗口。
